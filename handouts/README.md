# Case 001 — Classroom handouts

Documents are provided in both PDF and editable Word formats.

| File prefix | Audience | Recommended release |
| --- | --- | --- |
| `01_Measles_and_Vaccine_History_Fact_Sheet` | Students | Page 1 at stage 1, remaining page(s) at stage 5 |
| `02_FICTIONAL_Consent_Form_For_Critique` | Students | Stage 2 |
| `03_Instructor_Moderator_Guide` | Instructors | Before the exercise — not for student distribution |

**Important:** The consent form is a fictional teaching reconstruction, not an archival or historical reproduction. The actual Los Angeles study involved signed parental research consent that failed to disclose material facts about a vaccine's investigational status.

**Public repository warning:** A public GitHub repository exposes instructor materials to anyone who browses the repository or guesses their direct URL. Instructors who require secure progressive release must remove the instructor guide from the public repository and store it privately.
